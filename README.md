# NaijaSensei

**An AI study partner for Nigerian secondary school students preparing for WAEC.**
It answers in English, Pidgin, Yoruba, Hausa and Igbo, grounds its answers in WAEC curriculum content, and keeps working when the internet doesn't.

Built for the Gemma 4 Good Hackathon, Future of Education track.

---

## What students can do

| Feature | What it does |
| --- | --- |
| **Chat tutor** | Ask anything from your registered WAEC subjects. Replies match the language you write in. Each subject and topic gets its own persistent chat thread. |
| **Socratic Mode** | Gives the full answer, then asks one or two short questions to check you understood. |
| **Homework Assistant** | Upload a photo or file of your homework. It guides you step by step and points out mistakes instead of just handing over answers. |
| **Exam practice** | Quick Practice, a full Real WAEC Simulation, or a Custom exam. Exams can be saved for offline use. |
| **Past questions** | Practise with past WAEC-style questions by subject and topic. |
| **Analytics and Topic Mastery** | Strengths, weak topics, score trends and a study plan based on your exam date. The tutor uses your weak topics to suggest what to study next. |
| **Pass Predictor** | A readiness estimate for each registered subject based on your practice results. |
| **Career and Scholarships** | Career guidance and funding opportunities. |
| **Voice** | Speak your questions and have replies read aloud, using browser speech recognition and synthesis. |
| **Study streaks and activity** | Daily streak and minutes-studied tracking. |

## For teachers and parents

- **Classroom and Teacher Dashboard:** create classes, monitor student progress, and send announcements to a class.
- **Parent Dashboard:** link to a child's account with a share code and follow their learning progress.
- **Broadcasts:** admin and teacher messages show up in a notification bell in the app.
- **Admin panel:** manage topics, send broadcasts, and review provider usage.

## How it works

**Retrieval-grounded answers.** Each question is matched against indexed curriculum content (ChromaDB with sentence-transformers embeddings). Strong matches are passed to the model as its source of truth, and answers are scoped to the subjects the student registered for.

**Multi-provider fallback chain.** The server tries AI providers in priority order and skips any without an API key, so one provider's outage or quota limit never stops a student. The chain covers DeepSeek, NVIDIA NIM, Mistral, Google Gemini, Cerebras, OpenRouter, Together, Cohere, and many more, with a local Ollama model (Gemma 3n) as the last resort. Providers that fail are put on a short cooldown. Image questions are routed only to vision-capable providers (Gemini, Mistral Pixtral).

**Offline modes.**
- *Server side:* when the host machine has no internet, replies come from a local model through Ollama.
- *On the student's device:* in Settings, a student can download a small model (Qwen2.5 0.5B, Llama 3.2 1B or Gemma 2 2B) once and keep chatting with no connection, using WebLLM in the browser. A service worker caches the app shell so it launches offline.

**Nigerian languages.** English, Pidgin and any language the student writes in are handled directly. For Yoruba, Hausa and Igbo, the tutor writes a clear English answer, which is then machine-translated into the student's language, with a note that the translation may be imperfect.

**Background replies and push notifications.** Replies are generated by a background job, so if a student closes the tab or loses signal the reply still finishes, is saved to their history, and (if enabled) triggers a push notification.

**Student safety.**
- The tutor stays within academic topics, with a fast pre-filter for clearly off-topic or prompt-injection messages.
- Messages that signal sadness, distress or abuse are never redirected with a refusal. They get a caring response that encourages talking to a trusted adult or counsellor.

## Security and operations

- JWT authentication, with roles for students, teachers, parents and admins
- Security headers and per-IP rate limiting
- Required secrets (`JWT_SECRET_KEY`, `ADMIN_PASSWORD`, `CREDENTIALS_ENCRYPTION_KEY`) are checked at startup, and the server refuses to run with missing or weak values
- Free tier with daily and monthly limits, and Premium plans paid through Paystack
- Docker and local deployment guides (`DEPLOY.md`, `LOCAL_DEPLOYMENT.md`), plus a SQLite to Postgres migration script

## Tech stack

FastAPI and Uvicorn, SQLite (Postgres supported), ChromaDB, sentence-transformers, httpx, a single-page vanilla JS frontend (PWA with service worker), WebLLM for in-browser inference, Ollama for local inference.

## Run it locally

```bash
git clone https://github.com/goodnessoddy-ops/naija-sensei.git
cd naija-sensei
pip install -r requirements.txt
cp .env.example .env     # then fill in your keys
uvicorn server:app --reload
```

Set at least these in `.env`:

```
JWT_SECRET_KEY=...            # python -c "import secrets; print(secrets.token_hex(32))"
ADMIN_PASSWORD=...
CREDENTIALS_ENCRYPTION_KEY=...
GOOGLE_API_KEY=...            # plus any other provider keys you have
```

Every extra provider key you add makes the app more resilient. See `LOCAL_DEPLOYMENT.md` for the full setup, including Ollama for offline mode.
